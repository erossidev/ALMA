# ALMA Cognitive Architecture v4.0

## Visione

ALMA è un sistema cognitivo modulare. I modelli AI sono organi
specializzati per linguaggio e ragionamento; memoria, pianificazione e
coordinamento appartengono ad ALMA.

## Principi

1.  Ogni organo ha una sola responsabilità.
2.  Il Brain conserva conoscenza ma non prende decisioni.
3.  Ogni input viene interpretato una sola volta.
4.  Gli organi lavorano sull'Execution Context.
5.  Gli organi non comunicano direttamente tra loro.
6.  Solo l'Executive Cortex crea il piano cognitivo.

## Architettura

INPUT → Perception Engine → Executive Cortex → Cognitive Planner →
Execution Context → Task Executor → Dialogue Engine → Learning Engine →
Knowledge Engine → Brain → Memory Retrieval → Context Builder → AI
Orchestrator → OUTPUT

## Sistema Nervoso Cognitivo

### Perception Engine

-   Analizza input
-   Identifica entità
-   Risolve pronomi
-   Determina intento

### Executive Cortex

-   Pianifica
-   Decide il flusso
-   Produce il Cognitive Plan

### Cognitive Planner

Converte la percezione in Cognitive Task.

### Task Executor

Distribuisce i task agli organi.

-   Nessun organo interpreta direttamente il testo.
-   Nessun organo chiama un altro organo.
-   Solo il Sistema Nervoso coordina il flusso.
