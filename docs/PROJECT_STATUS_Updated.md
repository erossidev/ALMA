# Visione

Il flusso cognitivo di ALMA diventa:

Utente ↓ Dialogue Engine ↓ Cognitive Engine ↓ Learning Engine ↓
Knowledge Engine ↓ Brain ↓ Memory Retrieval ↓ Context Builder ↓ AI
Orchestrator ↓ Provider AI ↓ Risposta

ALMA non è un chatbot.

È un sistema cognitivo con memoria indipendente dai modelli AI.
