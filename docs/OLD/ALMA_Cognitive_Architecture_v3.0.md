# ALMA Cognitive Architecture v3.0

## Visione

ALMA è un sistema cognitivo modulare ispirato al funzionamento del
cervello umano.

L'intelligenza appartiene ai modelli AI. La conoscenza appartiene al
Brain. Il codice coordina il flusso cognitivo attraverso il Sistema
Nervoso.

## Principi

1.  Ogni componente ha una sola responsabilità.
2.  Il Brain conserva conoscenza, non prende decisioni.
3.  Ogni messaggio viene interpretato una sola volta.
4.  Tutti gli organi condividono lo stesso stato cognitivo.
5.  L'Executive Controller è l'unico componente che decide il flusso.
6.  Gli organi non comunicano direttamente tra loro.
7.  Tutta la comunicazione avviene tramite il Sistema Nervoso.

## Architettura

INPUT -\> Perception Engine -\> Executive Controller -\> Dialogue Engine
-\> Working Thought -\> Brain -\> Memory Conflict Resolver -\> Learning
Engine -\> Knowledge Engine -\> Memory Retrieval -\> Context Builder -\>
AI Orchestrator -\> Response

## Sistema Nervoso

### Perception Engine

-   Analizza l'input una sola volta.
-   Identifica entità.
-   Risolve i pronomi.
-   Determina l'intento.

### Executive Controller

-   Pianifica il ciclo cognitivo.
-   Decide quali organi eseguire.
-   Evita elaborazioni inutili.

### Working Thought

-   Mantiene il ragionamento corrente.
-   Conserva risultati temporanei.
-   Gestisce il focus cognitivo.

### Memory Conflict Resolver

-   Individua conflitti tra nuove informazioni e Brain.
-   Prepara il Learning.
