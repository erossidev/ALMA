# ALMA Ontology v1

## Manifesto del Linguaggio Cognitivo

Versione: 1.0 (Bozza Fondativa)

------------------------------------------------------------------------

# Visione

ALMA non memorizza dati.

ALMA costruisce una rappresentazione del mondo attraverso un **grafo
cognitivo** composto esclusivamente da:

-   Neuroni
-   Sinapsi

Ogni conoscenza permanente deve poter essere rappresentata come un
insieme di neuroni collegati da relazioni semantiche.

------------------------------------------------------------------------

# Principi

1.  Il Brain contiene solo neuroni e sinapsi.
2.  Ogni relazione appartiene all'Ontology.
3.  L'Ontology è l'unica fonte di verità del linguaggio del Brain.
4.  Il Knowledge Translator traduce il linguaggio naturale nel
    linguaggio dell'Ontology.
5.  Il Brain non interpreta il significato delle relazioni: le memorizza
    soltanto.
6.  Ogni nuova relazione deve essere descritta, documentata e
    categorizzata.
7.  Se ALMA non conosce una relazione, chiede all'utente invece di
    inventarla.

------------------------------------------------------------------------

# Architettura

Utente ↓ Dialogue ↓ Language ↓ Knowledge Translator ↓ Ontology ↓ Brain ↓
Retrieval ↓ Risposta

------------------------------------------------------------------------

# Componenti

## Brain

Responsabilità:

-   Memorizzare neuroni
-   Memorizzare sinapsi
-   Gestire gli stati dinamici
-   Recuperare i ricordi

Il Brain NON conosce il significato delle relazioni.

------------------------------------------------------------------------

## Ontology

Responsabilità:

-   Definire tutte le relazioni
-   Organizzarle per categoria
-   Fornire alias
-   Fornire descrizioni
-   Fornire esempi
-   Gestire l'evoluzione del linguaggio

------------------------------------------------------------------------

## Knowledge Translator

Responsabilità:

-   Comprendere il testo
-   Individuare i concetti
-   Tradurli in neuroni e sinapsi
-   Usare esclusivamente relazioni presenti nell'Ontology

------------------------------------------------------------------------

## Learning Engine

Quando una relazione non esiste:

1.  Cerca relazioni simili.
2.  Chiede conferma all'utente.
3.  Se necessario crea una nuova relazione.
4.  Aggiorna l'Ontology.

------------------------------------------------------------------------

## State Engine

Responsabilità:

-   Confidence
-   Importance
-   Weight
-   Plasticity
-   Emotional Weight
-   Decay Rate
-   Permanence

------------------------------------------------------------------------

# Regole Fondamentali

-   Nessuna memoria parallela.
-   Nessun "fact" separato.
-   Tutta la conoscenza passa attraverso il grafo.
-   Ogni informazione deve essere rappresentabile tramite neuroni e
    sinapsi.

------------------------------------------------------------------------

# Evoluzione

L'Ontology nasce con un vocabolario di base.

Successivamente cresce insieme all'utente.

Le nuove relazioni vengono apprese tramite il Learning Engine.

------------------------------------------------------------------------

# Obiettivo Finale

ALMA non è un chatbot.

ALMA è un sistema cognitivo che orchestra modelli AI mantenendo una
memoria persistente, interpretabile ed evolutiva basata su un grafo di
conoscenza.
